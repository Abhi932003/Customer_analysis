Data Analytics Project
Overview

This project demonstrates a complete Data Analytics workflow using Python, SQL, and Power BI. The project includes data loading, cleaning, exploratory data analysis (EDA), SQL querying, dashboard creation, reporting, and presentation building. The main goal was to transform raw data into meaningful business insights and visualizations.

Dataset

The dataset used in this project contains structured business/sales/customer-related data for analysis purposes.
